# M1 骨架 Implementation Plan（Cowork Data Studio）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Worker model policy:** 實作 subagent 一律用 **sonnet**（複雜整合任務可用 opus），主迴圈負責驗收。

**Goal:** 建立前後端專案骨架：Spring Boot API（session CRUD + Oracle schema）、React 三欄靜態 UI（側欄接真 API）、docker compose（oracle/backend/frontend/cloudflared tunnel，local 用）。

**Architecture:** 後端 Spring Boot 3 MVC + JPA（dev 預設 H2 Oracle-mode，compose 跑 Oracle Free）；前端 Vite + React 18 + TS，antd + Tailwind v4，扁平目錄；nginx 反代 `/api` 讓前端永遠用相對路徑。

**Tech Stack:** Java 21 / Spring Boot 3.4.1 / Maven、React 18 / Vite / TypeScript / antd 6 / @ant-design/x / Tailwind v4 / Vitest、Oracle Free 23 / cloudflared。

**Spec:** `docs/superpowers/specs/2026-07-05-cowork-data-studio-design.md`（mockup 參照 `docs/eRDWorkspaceonline.html`）

## Global Constraints

- 後端 package root：`com.erd.cowork`；Java 21；Spring Boot `3.4.1`；建置用 Maven wrapper（`./mvnw`）
- Java 格式：google-java-format（Claude hook 已自動跑；Spotless 只作為 build 驗證，不在每步手動執行）
- 前端僅 Cowork 一頁，**扁平目錄**（不做 features 分層）；UI 文案照 mockup 用英文
- 前端鎖 **React 18**（react/react-dom/@types 一律 ^18.x，不用 React 19）
- 前端 API 一律走相對路徑 `/api`（dev 用 Vite proxy，部署用 nginx proxy）
- Entity ID 一律 `String`（Hibernate `@UuidGenerator`）；時間戳一律 JPA Auditing（`@CreatedDate`/`@LastModifiedDate`，`@EnableJpaAuditing` 放主程式類）；大欄位用 `@Lob`
- Java 實作遵循 spring-boot / java-code-quality skills 慣例：constructor injection（不用 field injection）、DTO 用 record、例外統一走 `@RestControllerAdvice`
- Health 檢查用 Spring Boot Actuator（`GET /actuator/health`），不自寫 controller
- v1 檔案儲存用 local disk（`LocalDiskStorage` + compose volume）；`S3FileStorage` 留待公司環境（`erd.storage.type=local|s3` 切換）；docker compose 定位為 **local 開發/demo 用**
- DB：dev 預設 `jdbc:h2:mem:local;MODE=Oracle`，compose 用 Oracle Free（`FREEPDB1`）
- Schema 一律由 **Flyway** 管理（`backend/src/main/resources/db/migration/V*__*.sql`，DDL 同時相容 Oracle 與 H2 Oracle mode）；`ddl-auto: none`（NEVER 用 ddl-auto 建/改表；validate 因 H2/Oracle 型別對映差異易誤判，不用）
- 測試：後端 JUnit5 + AssertJ（spring-boot-starter-test 內建）；前端 Vitest + Testing Library
- 不做認證；Slides 功能不做（UI 佔位即可）
- macOS 上 docker build/pull 若卡在 credential helper，用 `DOCKER_CONFIG=$(mktemp -d) docker compose ...` 繞過
- 所有程式碼 MUST 遵守根目錄 `CLAUDE.md` rules（Lombok/@RequiredArgsConstructor、MapStruct、springdoc 註解、React.FC、useSuspenseQuery、apiClient 等）——implementer 動工前先讀 CLAUDE.md 與對應 skills
- 使用者識別一律 `X-User-Id` header（v1 前端 localStorage 匿名 UUID 自動附加；公司環境由 SSO/gateway 注入）；所有 session 查詢以 userId 過濾，存取他人資源一律 404

import com.erd.cowork.domain.ChatMessage;
import com.erd.cowork.domain.ChatSession;
import com.erd.cowork.domain.Sender;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.autoconfigure.jdbc.AutoConfigureTestDatabase;
import org.springframework.boot.test.autoconfigure.orm.jpa.DataJpaTest;

@DataJpaTest
@AutoConfigureTestDatabase(replace = AutoConfigureTestDatabase.Replace.NONE)
class RepositoryTest {

  @Autowired ChatSessionRepository sessions;
  @Autowired ChatMessageRepository messages;

  @Test
  void sessionRoundTripGeneratesUuidAndTimestamps() {
    ChatSession s = new ChatSession();
    s.setTitle("New analysis");
    s.setUserId("u1");
    ChatSession saved = sessions.save(s);
    assertThat(saved.getId()).isNotBlank();
    assertThat(saved.getCreatedAt()).isNotNull();
    assertThat(saved.getUpdatedAt()).isNotNull();
  }

  @Test
  void messagesOrderedByCreatedAt() {
    ChatSession s = new ChatSession();
    s.setTitle("t");
    s.setUserId("u1");
    s = sessions.save(s);

    ChatMessage m1 = new ChatMessage();
    m1.setSessionId(s.getId());
    m1.setSender(Sender.USER);
    m1.setText("q1");
    messages.save(m1);

    ChatMessage m2 = new ChatMessage();
    m2.setSessionId(s.getId());
    m2.setSender(Sender.AI);
    m2.setText("a1");
    messages.save(m2);

    assertThat(messages.findBySessionIdOrderByCreatedAtAsc(s.getId()))
        .extracting(ChatMessage::getText)
        .containsExactly("q1", "a1");

}

package com.erd.cowork.service;

import com.erd.cowork.domain.ChatSession;
import com.erd.cowork.repo.ChatMessageRepository;
import com.erd.cowork.repo.ChatSessionRepository;
import com.erd.cowork.repo.UploadedFileRepository;
import com.erd.cowork.web.dto.MessageDto;
import com.erd.cowork.web.dto.SessionDetailDto;
import com.erd.cowork.web.dto.SessionMapper;
import com.erd.cowork.web.dto.SessionSummaryDto;
import java.util.List;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
@RequiredArgsConstructor
@Transactional
public class SessionService {

  private final ChatSessionRepository sessions;
  private final ChatMessageRepository messages;
  private final UploadedFileRepository files;
  private final SessionMapper mapper;

  public SessionSummaryDto create(String userId) {
    ChatSession s = new ChatSession();
    s.setTitle("New analysis");
    s.setUserId(userId);
    s = sessions.save(s);
    return mapper.toSummary(s);
  }

  @Transactional(readOnly = true)
  public List<SessionSummaryDto> list(String userId) {
    return sessions.findByUserIdOrderByUpdatedAtDesc(userId).stream()
        .map(mapper::toSummary)
        .toList();
  }

  @Transactional(readOnly = true)
  public SessionDetailDto get(String userId, String id) {
    ChatSession s =
        sessions.findById(id).orElseThrow(() -> new NotFoundException("session not found: " + id));
    if (!s.getUserId().equals(userId)) {
      throw new NotFoundException("session not found: " + id);
    }
    List<MessageDto> msgs =
        messages.findBySessionIdOrderByCreatedAtAsc(id).stream()
            .map(mapper::toMessageDto)
            .toList();
    var fs = files.findBySessionId(id).stream().map(mapper::toFileDto).toList();
    return new SessionDetailDto(s.getId(), s.getTitle(), s.getCreatedAt(), msgs, fs);
  }
}

import { useMutation, useSuspenseQuery, useQueryClient } from '@tanstack/react-query';

import { MenuUnfoldOutlined } from '@ant-design/icons';
import ChatHistorySidebar from './components/ChatHistorySidebar';
import { createSession, listSessions } from '@/api/sessionApi';

const CoworkPage: React.FC = () => {
  const queryClient = useQueryClient();
  const { data: sessions } = useSuspenseQuery({
    queryKey: ['sessions'],
    queryFn: listSessions,
  });

  const [activeSessionId, setActiveSessionId] = useState<string | null>(null);
  const [sidebarOpen, setSidebarOpen] = useState(true);
  const autoCreatedRef = useRef(false);

  const createMutation = useMutation({
    mutationFn: createSession,
    onSuccess: (created) => {
      queryClient.invalidateQueries({ queryKey: ['sessions'] });
      setActiveSessionId(created.id);
    },
  });

  // Auto-create first session when list is empty (run at most once)
  useEffect(() => {
    if (sessions.length === 0 && !autoCreatedRef.current) {
      autoCreatedRef.current = true;
      createMutation.mutate();
    }
  }, [sessions, createMutation]);

  // Default active to first session when list changes and nothing is selected
  useEffect(() => {
    if (sessions.length > 0 && activeSessionId === null) {
      setActiveSessionId(sessions[0].id);
    }
  }, [sessions, activeSessionId]);

  const handleNew = useCallback(() => {
    createMutation.mutate();

import React, { useCallback, useState } from 'react';
import { Button } from 'antd';
import { ArrowUpOutlined, PlusOutlined } from '@ant-design/icons';

export interface Props {
  disabled?: boolean;
  onSend: (text: string) => void;
}

const PromptSender: React.FC<Props> = ({ disabled, onSend }) => {
  const [value, setValue] = useState('');

  const send = useCallback(() => {
    const t = value.trim();
    if (!t || disabled) return;
    onSend(t);
    setValue('');
  }, [value, disabled, onSend]);

  return (
    <div className="flex items-end gap-2 rounded-2xl border border-gray-300 bg-white p-2">
      <Button type="text" size="small" icon={<PlusOutlined />} disabled />
      <textarea
        value={value}
        onChange={(e) => setValue(e.target.value)}
        onKeyDown={(e) => {
          if (e.key === 'Enter' && !e.shiftKey) {
            e.preventDefault();
            send();
          }
        }}
        placeholder='Ask eRD AI to analyze your data…  e.g. "build an SPC dashboard for Vt"'
        rows={1}
        className="max-h-24 flex-1 resize-none border-none bg-transparent py-1 text-[13px] leading-relaxed outline-none"
      />
      <Button
        type="primary"
        shape="default"
        icon={<ArrowUpOutlined />}
        onClick={send}
        disabled={disabled}
      />
    </div>
  );
};

export default PromptSender;

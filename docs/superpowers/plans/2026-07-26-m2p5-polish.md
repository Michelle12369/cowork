### Task 7:具名方法庫擴充(可在 Task 3-5 之間任意排程)

**Files:** Create `app/engine/methods/{summary_stats,group_compare,time_aggregate,moving_average,histogram,pareto,correlation,process_capability}.py`;Modify `app/agent/toolbelt.py`(工具包裝+標題)、`app/agent/prompts.py`(一句話:優先具名方法);Test `tests/test_methods.py` 擴充

**介面(全部 `connection in / QueryResult out`,沿既有紀律:`\w+` 白名單、never-raise、SQL 計算、TABLE-eligible 固定意圖):**
- `summary_stats(connection, table, columns=None)` — 每數值欄 count/mean/std/min/q25/median/q75/max(DuckDB quantile);columns=None 時自動選數值欄
- `group_compare(connection, table, group_column, value_column, agg="mean")` — 分群 agg+count+佔比,agg ∈ mean/median/sum/count(Literal 驗證)
- `time_aggregate(connection, table, time_column, value_column, grain="day", agg="mean")` — date_trunc 聚合,grain ∈ day/week/month
- `moving_average(connection, table, time_column, value_column, window=7)` — 時序排序後 window AVG;window 驗 2..365
- `histogram(connection, table, column, bins=20)` — 等寬分箱計數(width_bucket 或等價;bins 驗 2..100;全常數欄的除零防護)
- `pareto(connection, table, category_column, value_column)` — 按類別加總降冪+累積佔比欄
- `correlation(connection, table, column_a, column_b)` — DuckDB corr() 單列結果(r、n);非數值欄 → SQL_ERROR 傳遞
- `process_capability(connection, table, value_column, usl, lsl)` — mean/std(樣本)/Cp/Cpk/超規 ppm(SQL 計算;usl/lsl 為 float 參數驗 finite 且 usl>lsl;std=0 防護 → 錯誤字串說明)
- 中文步驟標題:敘述統計/分群比較/時間聚合/移動平均/分佈直方/柏拉圖分析/相關係數/製程能力
- 固定意圖字串同標題語意;每個方法至少 3 條測試(正常/惡意識別字/域邊界如 std=0、bins=1、usl<lsl)

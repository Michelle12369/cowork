# M4 Artifact Implementation Plan（Cowork Data Studio）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox syntax.
>
> **Worker model policy:** implementer/task reviewer 用 sonnet（複雜整合 opus）、終審 opus。

**Goal:** Dashboard 真正渲染：`__ERD_DATA__` 資料注入（stride 抽樣）、`GET /api/artifacts/{id}` 出 HTML、右欄 iframe 渲染 + 全螢幕開啟 + Regenerate。外加使用者要求的 agent package 重構。

**Architecture:** finalize 時 `ArtifactAssembler` 把非 expired 檔案自 storage 重新串流解析成 rows（以 profile.rowCount 已知總數做 stride 均勻抽樣，cap 20 萬列/30MB per file），組 `window.__ERD_DATA__` script 注入 LLM 產出的 HTML 後存 DB。Artifact GET 為 **capability URL**（UUID 不可猜；iframe/新分頁帶不了 X-User-Id header——v1 取捨，hardening 延後）。

**Spec:** `docs/superpowers/specs/2026-07-05-cowork-data-studio-design.md` §4
**Base branch:** `feat/m4-artifact`（自 master @ M3 squash）

## Global Constraints

- 沿用 CLAUDE.md rules 全部
- 注入契約（§4）：`window.__ERD_DATA__ = { "<alias>": { "columns": [...], "rows": [[...],...], "sampled": bool, "totalRows": N } }`；抽樣上限 per file：`erd.artifact.max-rows`（預設 200000）與 `erd.artifact.max-bytes`（預設 31457280=30MB，rows JSON 估算）；超限做 **stride 均勻抽樣**（步長 ceil(N/cap)，單趟）
- script 注入位置：HTML 含 `<head>` → 插在 `<head>` 之後；否則前置於整份 HTML
- `GET /api/artifacts/{id}`：`text/html; charset=utf-8`、404 JSON（沿用 error body）、**不做 user 檢查**（capability URL；spec 註記 + deferred hardening）
- iframe `sandbox="allow-scripts"`（不加 allow-same-origin）
- 解析層重構規則：CSV/xlsx 迭代邏輯不得複製貼上——抽出 `RowVisitor` 讓 profile 與資料萃取共用同一迭代
- 環境：Java 21 portable（JAVA_HOME 同前）；docker workaround 同前

### Task 2: RowVisitor 重構 + 抽樣資料萃取

**Files:**
- Create: `backend/src/main/java/com/erd/cowork/parsing/RowVisitor.java`
- Create: `backend/src/main/java/com/erd/cowork/parsing/SamplingRowCollector.java`
- Modify: `CsvParsingService` / `XlsxParsingService`（迭代改餵 RowVisitor；`parse()` 保持相容——內部用 RowProfiler visitor）
- Modify: `RowProfiler`（implements RowVisitor）
- Create: `backend/src/main/java/com/erd/cowork/config/ArtifactProperties.java`
- Modify: `application.yml`（`erd.artifact.max-rows/max-bytes`）
- Tests: SamplingRowCollectorTest + 既有 parser 測試不變綠

**Interfaces:**
```java
public interface RowVisitor {
  void onHeader(java.util.List<String> headers);
  void onRow(java.util.List<String> row);
}
// 兩個 parser 各加：public void stream(InputStream in, RowVisitor visitor)（既有 parse() 委派：new RowProfiler 餵完回 finish()）
// FileParsingService 加：public void streamRows(String filename, InputStream in, RowVisitor visitor)（副檔名分派同 parse）

public class SamplingRowCollector implements RowVisitor {
  public SamplingRowCollector(long totalRows, int maxRows, long maxBytes) {} // totalRows 來自 profile.rowCount()
  // stride = max(1, ceil(totalRows / maxRows))；只收 index % stride == 0 的列
  // bytes 估算：每列累加 cell 長度和（UTF-8 概略），超過 maxBytes 即停止收集（sampled=true）
  public java.util.List<String> headers();
  public java.util.List<java.util.List<String>> rows();
  public boolean sampled();     // stride>1 或 bytes 截斷
  public long totalRows();
}

@ConfigurationProperties(prefix = "erd.artifact")
public record ArtifactProperties(int maxRows, long maxBytes) {}
```

**測試重點:** stride 抽樣正確（totalRows=10, max=3 → stride 4 → rows 0,4,8）；未超限不抽樣 sampled=false；bytes 截斷；xlsx 路徑 smoke。

**Commit:** `refactor(backend): row visitor abstraction with sampling collector`

### Task 3: ArtifactAssembler + orchestrator 整合

**Files:**
- Create: `backend/src/main/java/com/erd/cowork/agent/artifact/ArtifactAssembler.java`
- Modify: `AgentOrchestrator`（finalize：html 非空時先經 assembler 注入再存）

**Interfaces:**
```java
@Component @RequiredArgsConstructor @Slf4j
public class ArtifactAssembler {
  // deps: FileStorage, FileParsingService, UploadedFileRepository, ArtifactProperties, ObjectMapper
  /** 讀取 session 非 expired 檔案 → streamRows + SamplingRowCollector → 組 data map → 注入 script。
   *  單一檔案讀取/解析失敗：log.warn 該檔 skip（data 缺該 alias），不使整體失敗。 */
  public String assemble(String sessionId, String rawHtml);
}
// data map value 形狀：{"columns": headers, "rows": rows, "sampled": bool, "totalRows": N}
// 注入：rawHtml 含 "<head>"（case-insensitive 第一個）→ 其後插入 "\n<script>window.__ERD_DATA__ = {...};</script>"；否則前置
// script 內 JSON 需防 </script> 逃逸：序列化後 replace("</", "<\\/")
```
- orchestrator finalize：`String injected = artifactAssembler.assemble(sessionId, ex.html()); artifact.setHtml(injected);`（在 boundedElastic 內，已是）
- totalRows 來源：UploadedFile.rowCount（DB 有）；為 null 時退化為先 profile 再收集或直接 stride=1 收滿 cap——實作擇一並測試

**測試重點:** 注入位置（有/無 head）；`</script>` 逃逸；alias 對映；單檔失敗跳過；MessageControllerTest happy path 的 artifact html 含 `window.__ERD_DATA__` 與 file1。
